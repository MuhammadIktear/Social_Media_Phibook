Description : Phibook is a dynamic social media platform designed for seamless user interaction. 
It allows users to sign up, create, edit, and delete posts with text, images, or videos, and 
engage through likes, comments, and follows. Users can manage profiles, update personal details, 
and securely change passwords. Additional features include browsing posts, connecting with others, 
and accessing support through the About and Contact pages.


Features :
Sign up, Login, Password Reset, View all posts, View profile, View other users' profiles, 
Create posts (text/photo/video), Edit/Delete posts, Like/Unlike posts, Comment, Edit/Delete comments,
Follow/Unfollow users, Edit profile, Password change, Logout, and more.


Technology used :
Frontend- HTML, CSS, JavaScript
Backend- Django, Django REST Framework
Database- SQLite (Django default)
